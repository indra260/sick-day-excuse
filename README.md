# The Funniest Sick-Day Excuse

One short original sick-day excuse for make.fun's [The Funniest Sick-Day Excuse](https://make.fun/c/u-zeroxfive-the-funniest-sick-day-excuse-37423a36): the writer wakes up, tries to stand, and their lower back immediately resigns — so they call in sick before the rest of them hands in its notice too. The joke treats the body like a disgruntled employee quitting mid-shift: half believable (everyone has had that morning), fresh (no fever, no dog, no dead grandmother), and the punch lands on the very last word.

## Run

```sh
python3 main.py
```

Writes the excuse to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`). Python 3.13 standard library only; deterministic, no network, no randomness.
